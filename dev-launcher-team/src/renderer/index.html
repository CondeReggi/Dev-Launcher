Para obtener el certificado y firmar contra Plexo, la app debe ejecutarse como administrador.

Devolucion (refund) Plexo

        
Simula la devolucion de dinero de un pago Plexo. Port del flujo DevolucionDeDineroHandler → RefundAsync del backoffice (POST {baseUrl}/Operation/Refund). Ingresa el OrderId: se busca en la base APP el monto (ImporteServicio / Importe) y el MetaReference (CodigoAutorizacionPasarela), y se envia la devolucion firmada con el certificado del store de Windows.

      


      

        
⚠

        

          No estas en modo administrador.
          
Para obtener el certificado y firmar contra Plexo, la app debe ejecutarse como administrador.
